# homebrew-redom

Homebrew tap for [Redom](https://github.com/yogeshvas/redom-ai-agent) — live menu-bar
status for Claude Code and other AI coding agents.

## Install

```
brew install --cask yogeshvas/redom/redom
```

Not yet notarized with an Apple Developer ID — see the cask's caveats for the
first-launch Gatekeeper workaround.
